The mods

Five mods in v1, all free. Enable only what you want: each one changes game memory while active and reverts cleanly when you disable it. No mod edits your save files. QA'd with a full campaign run through Shao Kahn: no crashes, no failed spawns, no stuck waves.

Legendary Dark Knight Mode

ldk_x3

Three times the enemies in every spawn group, as reinforcements. Boss fights stay vanilla. Every extra must fit in the memory the area has spare, so the game doesn't crash.

randomizer

Enemy randomizer. Permutes enemy types across every spawn slot in an area, using exactly the same enemy memory as the vanilla game.

unlock_all

Install

One download, one button. No Python, no file editing.

  1. Start Shaolin Monks Recomp once with your game, then close it.
  2. Download MKSM-Komplete-v1.zip from the latest release and unzip it.
  3. Double-click MKSM Komplete Installer. Windows may say "unknown publisher" the first time: choose More info > Run anyway.
  4. Press Install, then Play.

Prefer doing it by hand? In the Recomp launcher choose Mods > Install from file... and pick each .tar.xz from the zip's packages folder. Testers and contributors: the diagnostics probe and QA tools are a separate download, MKSM-Komplete-v1-contributor-tools.zip, on the same release page.

FAQ

Quick answers before you install.

Do I need to own the original game?

Yes. This pack ships no game files, emulator, or assets. You must supply your own legally obtained copy of Mortal Kombat: Shaolin Monks and run it through Shaolin Monks Recomp 0.2.0+.

Will these mods corrupt my save?

No. Every mod changes game memory only while it is enabled and never writes to your save files. Disable a mod and the game returns to its original behavior on the next load.

Can I run more than one mod at a time?

Generally yes. Legendary Dark Knight Mode and Shaolin Shuffle are designed to work together. Avoid enabling two mods that do the same job, and read each mod's notes for specifics.

What does "Experimental" or "Prototype" mean?

Experimental mods work but are incomplete - some cases are still being investigated. Prototype mods are scaffolding: the framework runs, but the gameplay effects are not wired up yet, so you will not see a change in game.

What is the MKSMK Probe for?

A diagnostic tool for testers. It changes nothing in the game and writes reports to the Recomp session log. It is not in the player download; it comes with the contributor tools for anyone helping track down a bug.

Will it add more characters?

Not in v1: it changes how the game plays, not who is in it, and it needs nothing extra. More Mortal Kombat characters as enemies and bosses are a later goal (see the roadmap); if that ever builds on another project's work, it will happen only with its author's permission and full credit.

Does it cost anything?

No. Every mod is and will stay 100% free, with no paywalls or locked features. Donations are welcome but entirely optional.
