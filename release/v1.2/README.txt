MKSM Komplete+ v1.2 (test build, 2026-10-27)

v1.1, plus the next rungs of the ladder, frozen together for a fresh-play test:

- Legendary Dark Knight Mode 3.11.0 (x3): Goro's Lair groups fill up to 9-12 Onis
  (reinforcements trickle in as enemies die); the fatality room stays vanilla.
  QA run 2026-10-26 through Goro's Lair: no crashes, no script errors.
- Extended Upgrades: XP Shop 0.11.1 (experimental). Pause > Moves: Basic Moves
  becomes Upgrades (Health +1..+4, Stamina +1..+4), Running Attacks becomes
  Weapons, undiscovered Fatalities can be bought, and every Specials row can be
  bought again as its EX move: hold L2 + the move's input (no R2) for 10x
  damage and a fast recovery, for half the blue bar.
- Time Rifts 0.2.0 (experimental, not yet seen live): the co-op rift portals in
  Wu Shi (map 1) and Goro's Lair (map 100) reload their area instead of leading
  on, so the fight can be replayed. Needs Solo Co-op Paths. If an area does not
  come back cleanly, disable the mod and reload the save.
- Shaolin Shuffle 0.6.6, Environmental Kill XP 2.0.0, Unlock All 1.1.0,
  Solo Co-op Paths 0.6.2: unchanged from v1.
- MKSMK Probe 0.12.0 (optional, diagnostics only). The set uses 49 of the
  Recomp's 64 routine scripts.

Install: Shaolin Monks Recomp launcher > Mods > Install from file > pick each .tar.xz.
From the project folder: MKSMK.bat > 2 (Test set), or drag this folder onto MKSMK.bat.

Requires Shaolin Monks Recomp 0.2.0+ and a legally obtained copy of the game.
No game files are included. Checksums: SHA256SUMS.txt
