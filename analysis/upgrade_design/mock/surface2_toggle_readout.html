VIEW 2 — THE TOGGLE COMBO (read from pad state at tick 0x1D23F0)

HOLD $ (R1)
+ ◀ ▶ D-pad
= focus a perk
HOLD $ (R1)
+ * (Square)
= toggle focused perk ON / OFF

Glyphs are the game's own button markers (DESIGN.md A.2). A perk can only be toggled ON once its lifetime-XP threshold is met; below that it shows OFF and ignores the combo. Pad-state address/layout is RE (DESIGN.md E, Rank 2).

VIEW 3 — TRANSIENT FEEDBACK VIA THE COMBO-RANK POPUP (optional)

DECAP ON
combo x7   +1,050 EXP

On toggle, the mod forces the combo-rank word to a re-purposed entry so the next combo popup briefly names the perk. Uses the three redundant Impossible slots [1657/1658/1659] (same hash key 3d85cdbc → two are free). Needs the combo-rank variable (RE); the popup function itself is not hookable (DESIGN.md F1).
